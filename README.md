# 📒 Daftarqarz — لیستی قەرز

> ئەپێکی ساکار و مۆدێرن بۆ تۆمارکردن و بەدواداچوونی قەرزەکان، بە زمانی کوردی (سۆرانی).

## ✨ تایبەتمەندییەکان

- ➕ زیادکردنی قەرزی نوێ (ناو، بڕ، دراو، وەسف، بەروار)
- 🗑️ سڕینەوەی قەرز
- ✅ نیشانکردنی قەرز وەک دانراو (پارەدراوە)
- 🔎 گەڕان و پاڵاوتن (هەموو / نەدراوە / دانراوە)
- 📊 ڕاپۆرتی کۆتایی (کۆی گشتی، ژمارەی قەرزەکان)
- 💾 پاشەکەوتکردن لە `localStorage` ـی وێبگەڕ
- 🌐 ڕووکاری تەواو بە **کوردی (سۆرانی)** و **RTL** (ڕاست بۆ چەپ)

## 🛠️ تەکنەلۆجیا

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React 18**

## 🚀 دامەزراندن و جێبەجێکردن

```bash
# پاکێجەکان دابمەزرێنە
npm install

# سێرڤەری گەشەپێدان دەستپێبکە (پۆرتی 3000)
npm run dev

# بیناکردن بۆ بەرهەمهێنان
npm run build
npm run start
```

دواتر بچۆ بۆ [http://localhost:3000](http://localhost:3000)
